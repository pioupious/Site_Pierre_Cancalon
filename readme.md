# 🌐 Portfolio – Pierre Cancalon

Un site web portfolio personnel au style rétro-futuriste / abyssal, conçu avec un design interactif, des animations CSS dynamiques et des éléments visuels originaux (fenêtres type *adware/pop-up* ludiques).

https://special-bassoon-62evwjq.pages.github.io/

---

## 📌 Aperçu du Projet

Ce projet a pour objectif de présenter mon parcours, mes compétences et mes projets à travers une interface web originale et immersive. Le design repose sur des teintes sombres et néon (violet/magenta) avec une typographie typée console (`Courier New`).

---

## 🛠️ Technologies Utilisées

- **HTML5** : Structure sémantique des pages.
- **CSS3** : Styling sur mesure, animations (`@keyframes`), mise en page réactive (`Flexbox` & `Media Queries`).
- **Design Responsive** : Adaptation pour mobile, tablette et écran large.

## 🚀 Installation & Utilisation Localement

1. **Cloner le dépôt :**

   ```bash
   git clone git@github.com:EpitechMscProPromo2029/T-WEB-500-PAR-5-1-webd04-21.git   ```

2. **Accéder au dossier :**

   ```bash
   cd votre-repo
   ```

3. **Ouvrir le projet :**

   - Lancez simplement `index.html` dans votre navigateur web, ou utilisez une extension comme **Live Server** sur Visual Studio Code pour un rafraîchissement automatique.

## ✨ Fonctionnalités Principales

- **Navigation fluide** entre les différentes sections du portfolio.
- **Effets visuels interactifs** : Survol des cartes, effets de lueur (*glow*), et zoom sur les images.
- **Animations Adware rétro** : Éléments décoratifs animés qui apparaissent en boucle pour un effet vintage / cyberpunk.
- **Formulaire de contact** stylisé et prêt à l'emploi.
- **Media Queries dédiées** pour une expérience de lecture optimale sur mobile et tablette.
